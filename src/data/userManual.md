## 快速开始

### 第一次使用

欢迎使用**皮老板智能阅卷工具**！本工具可以帮助您自动批改智学网作业，大大提升阅卷效率。

**首次使用需要完成以下三步配置：**

#### 第一步：配置 AI 服务商

1. 点击左侧边栏的「系统设置」
2. 进入「AI 与 OCR」标签页
3. 点击「添加服务商」按钮，选择您的 AI 服务商（如 DeepSeek、火山引擎、硅基流动等）
4. 填写 API Key 和模型名称
5. 点击「测试连接」验证配置是否正确
6. 保存设置

**支持的 AI 服务商：**
- DeepSeek（推荐，性价比高）
- 火山引擎（字节跳动）
- 硅基流动（开源模型）
- 自定义（兼容 OpenAI API 的服务商）

#### 第二步：配置 OCR 识别（可选）

如果需要识别学生作答的图片内容，可以配置 PaddleOCR 服务：

1. 在「AI 与 OCR」标签页中，启用「PaddleOCR」
2. 填写 PaddleOCR 的 Access Token 和服务地址
3. 保存设置

> **提示：** 如果不需要 OCR 功能，可以跳过此步骤，直接使用 AI 视觉模型识别图片。

#### 第三步：添加评分标准

1. 点击左侧边栏的「评分标准」
2. 点击「添加标准」按钮
3. 填写题目信息：
   - 题目名称（如"第一题"）
   - 满分值
   - 参考答案
   - 关键词（用于 AI 评分参考）
4. 保存评分标准

## 批改流程

### 基本批改流程

完成上述配置后，即可开始批改作业：

1. **进入批改页面**
   - 点击左侧边栏的「自动批改」（或「坐标批改」）

2. **输入智学网链接**
   - 复制智学网作业链接（支持 zhixue.com 和 zhixueyun.com）
   - 粘贴到链接输入框中

3. **选择评分标准**
   - 从下拉列表中选择要使用的评分标准

4. **选择批改模式**
   - **普通模式**：AI 评分后等待 5 秒，期间可以暂停或取消
   - **试改模式**：AI 评分后等待确认，支持分数纠错（推荐用于初次使用）
   - **无人值守模式**：全自动批改，适合大量作业

5. **开始批改**
   - 点击「开始自动批改」按钮
   - 工具会自动打开浏览器，登录智学网，逐份批改作业

### 批改模式详解

#### 普通模式

适合大多数场景，AI 评分后会等待 5 秒，您可以：
- 点击「暂停」按钮暂停批改
- 点击「停止」按钮停止批改
- 等待 5 秒后自动批改下一份

#### 试改模式

适合初次使用或需要严格质控的场景，AI 评分后会等待您确认：
- 查看 AI 给出的分数和评分理由
- 如果分数不准确，可以手动纠错
- 点击「确认」继续批改下一份
- AI 会根据您的纠错自动优化评分标准

#### 无人值守模式

适合大量作业批改，全自动无需人工干预：
- AI 自动评分并提交
- 遇到错误自动重试
- 可以在「批改记录」中查看进度和结果

### 空白卷处理

当检测到学生未作答（空白卷）时，可以选择：
- **手动确认**：暂停批改，等待您手动处理（推荐，最安全）
- **自动打 0 分**：自动评分为 0 分，继续批改下一份
- **自动跳过**：不评分，直接跳过，继续批改下一份

> **提示：** 您可以在「设置 - 基础设置」中配置空白卷处理方式。

## AI 配置

### 添加 AI 服务商

在「系统设置 - AI 与 OCR」页面，点击「添加服务商」按钮，选择预设的服务商或「自定义」。

#### 预设服务商

| 服务商 | API 端点 | 推荐模型 |
|--------|----------|----------|
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` | `deepseek-v4-flash` |
| 火山引擎 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions` | 根据实例填写 |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `Qwen/Qwen2.5-7B-Instruct` |

#### 自定义服务商

如果您的 AI 服务商不在预设列表中，可以选择「自定义」：
1. 填写服务商名称（如"我的 AI"）
2. 填写 API 端点地址（需要兼容 OpenAI API 格式）
3. 填写 API Key
4. 填写模型名称
5. 保存并测试连接

### 全局参数设置

在「AI 与 OCR」页面顶部，可以设置全局参数：

- **温度（Temperature）**：控制 AI 输出的随机性
  - 值越低（如 0.1），AI 回答越确定、越严谨
  - 值越高（如 1.0），AI 回答越随机、越有创意
  - 推荐值：0.7（平衡模式）

- **最大 Token**：控制 AI 回答的最大长度
  - Token 是文本的基本单位，大约等于 0.5-1 个汉字
  - 推荐值：2000（足够批改一个题目）

### 测试连接

配置完成后，点击服务商卡片上的「测试连接」按钮，工具会发送一条测试消息验证配置是否正确。

> **常见问题：**
> - 如果提示"连接失败"，请检查 API Key 是否正确、网络是否通畅
> - 如果提示"HTTP 401"，说明 API Key 无效或已过期
> - 如果提示"网络错误"，请检查防火墙或代理设置

## 导出功能

### 导出批改记录

批改完成后，可以在「批改记录」页面导出成绩：

1. 进入「批改记录」页面
2. 选择要导出的记录（或全选）
3. 点击「导出」按钮
4. 选择导出格式：
   - **Excel 格式（.xlsx）**：适合进一步分析和打印
   - **CSV 格式（.csv）**：适合导入其他系统
   - **JSON 格式（.json）**：适合程序处理

### 导出设置

您可以在「系统设置 - 帮助与支持」中导出当前设置，用于备份或迁移到其他电脑：

1. 进入「系统设置」
2. 切换到「帮助与支持」标签页
3. 点击「导出设置」按钮
4. 设置文件会保存到您的下载文件夹

### 导入设置

如果您之前导出了设置，可以在新电脑或重置后导入：

1. 进入「系统设置」
2. 切换到「帮助与支持」标签页
3. 点击「导入设置」按钮
4. 选择之前导出的设置文件（.json）
5. 确认覆盖当前配置

> **注意：** 导入设置会覆盖当前配置，请谨慎操作。

## 常见问题

### 安装和启动

#### Q: 提示"未找到可用的浏览器"怎么办？

**A:** 请确保已安装 Chrome 或 Edge 浏览器。如果已安装但仍然报错，请运行以下命令安装 Playwright 的浏览器：

```bash
npx playwright install chromium
```

#### Q: 软件启动后白屏怎么办？

**A:** 可能是渲染进程加载失败，请尝试：
1. 关闭软件，重新打开
2. 检查是否有防火墙或代理阻止了本地服务器（localhost:5173）
3. 如果问题依旧，请在 GitHub 提交 issue

### AI 评分相关

#### Q: AI 评分不准确怎么办？

**A:** 可以尝试以下方法：
1. 使用**试改模式**进行纠错，AI 会根据您的纠错自动优化评分标准
2. 完善评分标准中的「参考答案」和「关键词」
3. 调整 AI 的「温度」参数（降低温度可以提高严谨性）
4. 如果使用的是视觉模型，确保学生作答图片清晰

#### Q: AI 评分速度慢怎么办？

**A:** 可能的原因和解决方法：
1. AI 服务商响应慢 → 尝试更换服务商或模型
2. 网络延迟高 → 检查网络连接，使用国内服务商（如火山引擎、硅基流动）
3. 图片过大 → 在评分标准中配置图片压缩

#### Q: 提示"API Quota 不足"怎么办？

**A:** 这说明您的 AI 服务商账户余额不足，请前往服务商官网充值。

### OCR 识别相关

#### Q: OCR 识别失败怎么办？

**A:** 请检查：
1. 是否已启用 PaddleOCR 并填写了正确的 Access Token
2. Access Token 是否已过期（需要前往 PaddleOCR AI Studio 重新获取）
3. 学生作答图片是否清晰、完整
4. 如果问题依旧，可以尝试使用 AI 视觉模型直接识别图片（无需 OCR）

#### Q: OCR 识别结果不准确怎么办？

**A:** 可以尝试：
1. 更换 OCR 模型（在设置中选择 PP-OCRv5）
2. 提高图片分辨率
3. 确保学生作答区域没有被遮挡

### 导出和保存

#### Q: 导出的 Excel 文件打不开怎么办？

**A:** 可能是文件损坏或格式不兼容，请尝试：
1. 使用 Microsoft Excel 或 WPS 表格打开
2. 如果还是打不开，可以导出为 CSV 格式
3. 检查导出时是否有错误提示

#### Q: 批改记录丢失怎么办？

**A:** 批改记录会自动保存到本地数据库，如果丢失可能是以下原因：
1. 软件被卸载或数据目录被删除
2. 数据库文件损坏

建议定期导出批改记录备份。

## 快捷键

使用快捷键可以快速操作，提高效率。您可以在「设置 - 基础设置」中关闭或开启快捷键功能。

### 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `F1` | 打开帮助中心 |
| `Ctrl + K` | 快速搜索 |

### 批改页面快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Enter` | 开始/继续批改 |
| `Ctrl + P` | 暂停/继续批改 |
| `Ctrl + S` | 停止批改 |
| `Ctrl + E` | 打开纠错面板 |

### 快捷键使用技巧

- 快捷键需要在对应的页面才能生效
- 如果快捷键冲突，可以在设置中关闭「启用键盘快捷键」
- 开启「显示快捷键提示」后，按钮旁会显示对应的快捷键
